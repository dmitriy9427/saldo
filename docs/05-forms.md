# 05. Формы

[features/transaction-form](../src/features/transaction-form/) — react-hook-form + zod.

## Сумма — строка

В форме сумма хранится **строкой** («1 250,50»), в копейки превращается только при отправке
(`toInput`). Если хранить число, ввод ломается: «12,» → `NaN`, «0,0» → `0` и ноль съедает
запятую. Строку проверяет zod через `parseMoney`:

```ts
amount: z.string().trim()
  .min(1, 'Введите сумму')
  .refine((v) => !v || parseMoney(v) !== null, 'Не похоже на сумму')
  .refine((v) => (parseMoney(v) ?? 1) > 0, 'Сумма должна быть больше нуля'),
```

Вторая проверка пропускает нераспознанную сумму (`?? 1`) — иначе на «abc» было бы две ошибки
сразу. Это поймал тест ([урок 6](lessons.md)).

## Правила на несколько полей

Для перевода нужен второй счёт, для расхода — категория. Это `superRefine` на всей схеме с
`path` — ошибка встаёт под нужное поле:

```ts
.superRefine((v, ctx) => {
  if (v.type === 'transfer' && v.toAccountId === v.accountId)
    ctx.addIssue({ code: 'custom', path: ['toAccountId'], message: 'Выберите другой счёт' })
})
```

## Когда показывать ошибки

`mode: 'onSubmit', reValidateMode: 'onChange'`: пока человек печатает первый раз, не ругаемся;
после первой отправки ошибка исчезает, как только поле исправлено.

## Ошибки сервера под полями

Сервер проверяет всё ещё раз (клиенту доверять нельзя — запрос можно отправить в обход формы)
и отвечает `422 { fields: { note: '…' } }`. Форма показывает их так же, как свои:

```ts
catch (error) {
  const fields = fieldErrors(error)
  FIELDS.filter((name) => fields[name]).forEach((name) => setError(name, { message: fields[name] }))
}
```

Не известное форме поле → `setError('root', …)` — общая ошибка над кнопками.

## Доступность

- [Field](../src/shared/ui/field.tsx) связывает подпись, поле и ошибку: `htmlFor`, `aria-invalid`,
  `aria-describedby` — скринридер прочитает «Сумма, недопустимое значение, Введите сумму».
- Категории — группа радиокнопок: визуально это «чипы», но с клавиатуры работают стрелки.
- Переключатель «Расход / Доход / Перевод» — `role="radiogroup"`, стрелки ← →.
- Модалка — нативный `<dialog>` + `showModal()`: фокус-ловушка, Esc, возврат фокуса — бесплатно.
  Поле суммы получает фокус через `data-autofocus` ([урок 2](lessons.md)).

## useWatch вместо watch

`useWatch({ control, name: ['type', 'amount'] })` — подписка на конкретные поля: форма
перерисовывается только при их изменении. Смена типа сбрасывает несовместимую категорию.
