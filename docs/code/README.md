# Разбор кода: файл за файлом

Главы учебника объясняют **идеи** (Redux, RTK Query, FSD). Здесь — **конкретный код**:
каждый важный компонент и хук «Сальдо» разобран отдельно.

## Как устроена каждая страница

1. **Где на экране** — что это за кусок интерфейса.
2. **Что делает** — по пунктам, человеческим языком.
3. **Пропсы** — что принимает компонент, таблицей.
4. **Как пользоваться** — пример вызова.
5. **Код целиком** — порциями по 5–20 строк, после каждой порции объяснение.
6. **Что будет, если…** — уберите строку и посмотрите, что сломается.
7. **Проверьте себя** — вопросы с ответами под спойлером.
