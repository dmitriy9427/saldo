# 06. Деньги и даты

## Копейки

```js
0.1 + 0.2            // 0.30000000000000004
1.15 * 100           // 114.99999999999999
```

Числа с плавающей точкой хранят десятичные дроби неточно. На сотнях операций итог перестаёт
сходиться с суммой строк. Поэтому **везде целые копейки**: в API, в состоянии, в расчётах.
Целые складываются точно до 2^53 ≈ 9 × 10^15 копеек.

- `parseMoney('1 250,50')` → `125050`: разбираем **строку** (целая часть × 100 + две цифры
  дробной), а не `Number(s) * 100` — иначе «1,15» стало бы 114 копейками.
- `formatMoney(125050)` → «1 250,50 ₽» — рубли появляются только при показе.

Понимает разные записи: «1 234,5», «1234.50», «−200», «1 200 ₽», «2,000.00» (английский формат
выписок, где запятая — разделитель тысяч).

## Intl.NumberFormat

```ts
new Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB' }).format(1250.5) // «1 250,50 ₽»
```

- между разрядами и перед ₽ — неразрывные пробелы: сумма не разорвётся переносом;
- `signDisplay: 'exceptZero'` — «+500 ₽» у доходов;
- `notation: 'compact'` — «12,3 тыс.»; для осей графиков ещё короче — свой `formatAxis` («120к»);
- создавать форматтер дорого — кешируем по набору опций.

## Даты — строками без времени

`new Date('2026-10-01')` — полночь **по UTC**. В Москве это уже 03:00, а в Нью-Йорке — ещё
30 сентября. Для операции «купил хлеб 1 октября» время не нужно, а сдвиг на день — баг.

Поэтому дата операции — строка `'2026-10-01'`:
- сравнивается как строка: `'2026-09-30' < '2026-10-01'`;
- месяц — `date.slice(0, 7)`;
- «сегодня» — из **местной** даты (`toISODate(new Date())` берёт `getFullYear/Month/Date`, а не
  `toISOString`, который дал бы UTC).

## Падежи

date-fns знает именительный («октябрь», `LLLL`) и родительный («14 октября», `MMMM`).
Для «▼ 22 % к сентябрю» нужен дательный — [formatMonth(m, 'dative')](../src/shared/lib/date.ts)
строит его сам: «сентябрь» → «сентябрю», «май» → «маю», «март» → «марту».
