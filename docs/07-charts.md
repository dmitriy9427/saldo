# 07. Графики

Recharts 3 — графики из React-компонентов поверх SVG и d3. Самая тяжёлая зависимость
(~88 КБ gzip), поэтому страницы с графиками загружаются лениво (`lazy` в маршрутах).

## Размер: responsive

```tsx
<BarChart responsive style={{ width: '100%', height: 280 }} data={data}>
```

В Recharts 3 появился проп `responsive` — график следит за размером контейнера через обычные
CSS-правила. Раньше нужна была обёртка `ResponsiveContainer`.

## Цвета из CSS

```tsx
<Bar dataKey="income" fill="currentColor" className={s.income} />
```
```scss
.income { color: var(--income); }
```

`fill="currentColor"` + цвет классом: график перекрашивается при смене темы **без
перерисовки** — меняются только CSS-переменные. `fill="var(--income)"` в атрибуте SVG
работает не везде: в презентационных атрибутах CSS-переменные не по стандарту.

## Свои столбики и подсказки

- `shape` — свой компонент столбика: выбранный месяц яркий, остальные бледнее.
- `content` у `Tooltip` — своя подсказка: доходы, расходы и итог месяца.
- Клик по графику (`onClick` у `BarChart`, `activeTooltipIndex`) — выбор месяца для всей
  страницы; месяц живёт в адресе (`?month=2026-07`).
- `accessibilityLayer` — по графику можно ходить стрелками с клавиатуры.

## «Бублик» со связанным списком

[category-breakdown.tsx](../src/widgets/category-breakdown/ui/category-breakdown.tsx): общее
состояние `hovered` — наведение на сектор подсвечивает строку и наоборот, в центре — название
и сумма. Строка списка — ссылка на операции этой категории за месяц.

Шесть крупных категорий + «Остальное»: двенадцать тонких секторов не читаются.

## Баланс за год без отдельного запроса

[balance-history.ts](../src/widgets/accounts-overview/lib/balance-history.ts): известны
текущий баланс и итог каждого месяца (доходы − расходы). Идём от сегодня назад:
баланс на конец прошлого месяца = текущий − итог текущего месяца, и так далее. Переводы между
своими счетами общий баланс не меняют — их в отчёте нет.
