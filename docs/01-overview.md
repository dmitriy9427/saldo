# 01. Обзор и запуск

## Что умеет

- **Обзор** — деньги на всех счетах, доходы и расходы месяца со сравнением с прошлым,
  график за год (клик по столбику выбирает месяц), «бублик» расходов по категориям (клик по
  категории — её операции), бюджеты с темпом трат, последние операции.
- **Операции** — фильтры по периоду, типу, счёту, категории, поиск, сортировка, страницы.
  Всё это живёт в адресе: ссылкой можно поделиться, «Назад» возвращает прошлый фильтр.
- **Форма операции** — расход, доход, перевод между счетами. Открывается клавишей N из любого
  места, кликом по строке — на правку.
- **Удаление с отменой** — строка исчезает сразу, 5 секунд можно нажать «Отменить».
- **Бюджеты** — месячный лимит на категорию, полоса с отметкой «сегодня», прогноз к концу
  месяца, «можно тратить N ₽ в день».
- **Счета** — остатки и график общего баланса за год.
- **Импорт выписки** — CSV из интернет-банка: кодировка и колонки угадываются, категории
  подбираются по описанию, повторный импорт не задваивает операции.
- Светлая и тёмная тема, телефон (вкладки внизу и кнопка «+»), доступность с клавиатуры.

## Команды

```bash
npm install
npm run dev          # http://localhost:5173
npm run check        # линтеры, типы, тесты, сборка — то же, что в CI
npm run e2e          # Playwright: соберёт, поднимет preview и прогонит сценарии
```

## Карта папок

```
src/
  app/         точка входа, store, маршруты, глобальные стили
  pages/       страницы: раскладывают виджеты, держат состояние страницы (месяц в адресе)
  widgets/     крупные блоки: каркас, график, список операций, бюджеты, счета
  features/    действия пользователя: форма операции, удаление, фильтры, импорт, тема
  entities/    сущности: операция, счёт, категория, бюджет, отчёт — API и «глупые» компоненты
  shared/      без бизнес-логики: API-клиент, UI-кит, деньги и даты, демо-сервер
test/          помощники для тестов (store + MSW)
e2e/           сценарии Playwright
docs/          этот учебник
```

Почему именно так — [глава 04](04-fsd.md).

## Путь одного клика

Нажали «Добавить» в форме операции:

1. **features/transaction-form** — zod проверяет поля, сумма из строки становится копейками.
2. **entities/transaction** — мутация `createTransaction` отправляет `POST /api/transactions`.
3. **shared/mock** — MSW перехватывает запрос в Service Worker, «база» проверяет данные ещё
   раз и сохраняет операцию в localStorage.
4. **RTK Query** — мутация инвалидирует теги `Transaction LIST`, `Account`, `Stats`, `Budget`.
   Все запросы на экране с этими тегами перезапрашиваются сами.
5. **shared/model/toast** — тост «Добавлено: 1 250,50 ₽», модалка закрывается.

Ни одна страница не «обновляет себя» вручную — это главная идея RTK Query.
