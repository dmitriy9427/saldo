# Учебник по «Сальдо»

Учёт личных финансов, написанный так, чтобы по нему можно было учиться. Три главные темы —
то, что чаще всего спрашивают в вакансиях на React: **Redux Toolkit**, **RTK Query** и
архитектура **Feature-Sliced Design**. Плюс формы, деньги без ошибок округления, графики,
импорт банковской выписки и тесты от функций до браузера.

Каждая глава идёт от простого: **зачем** → **самый маленький пример** → **как сделано здесь** →
**ошибки** → **попробуйте сами** (ответы под спойлером). Начните с [главы 00](00-start.md).

## Как учиться на этом проекте

1. **Откройте демо и DevTools → Network.** Добавьте операцию (клавиша N) и посмотрите, какие
   запросы ушли после POST: список, счета, отчёты, бюджеты. Это инвалидация тегов (глава 03) —
   ни одна страница не просит «обнови меня».
2. **Поставьте Redux DevTools** и удалите операцию. В журнале экшенов видно сценарий
   «удалить → показать тост → ждать отмены → DELETE» (глава 02, listener middleware).
3. **Сломайте сервер:** в консоли `__saldo.controls.fail = true`, переключите месяц — увидите
   экраны ошибок с кнопкой «Повторить». `__saldo.controls.latency = 2000` — медленная сеть:
   видно скелетоны и полупрозрачные старые данные.
4. **Прочитайте [уроки](lessons.md)** — каждый баг там настоящий, и почти каждый спрашивают
   на собеседованиях в той или иной форме.
